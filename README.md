# Techmo Bloodborne

A Windows x64 launcher with English/Vietnamese UI, custom controls and performance tools.

- Keyboard/mouse bindings, profiles and graphics recommendations.
- Trophies, save backups, mods and online settings.
- FPS, CPU, GPU and VRAM overlay, session reports and benchmarks.

## Download & play

Download the **Windows ZIP** from [Releases](https://github.com/TechmoNoway/techmo_bloodborne_pc/releases/latest).
Extract, run `Techmo.cmd`, select your Bloodborne 1.09 folder and press **Play**.
Game files are not included.
